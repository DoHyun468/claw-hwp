클로드로 한글(HWP) 양식·서식 자동 채우기 — 개인정보 안전하게 (2026)

한 줄 요약: claw-hwp를 설치하면 클로드(Claude)·코덱스(Codex)가 엑셀·PDF에 흩어진 데이터를 한글 서식(.hwp)의 해당 칸에 자동으로 채워 줍니다. 주민등록번호·계좌번호 같은 값은 AI 대화에 올리지 않고 파일에서 바로 채우는 안전 모드가 있고, 무료 오픈소스(MIT)입니다.

매번 같은 서식에 이름·주민번호·주소를 손으로 채우고 있나요?

강사 이력서, 지원서, 견적서, 계약서, 각종 신청서 — 회사·기관의 한글 서식은 칸은 그대로인데 사람만 바뀌는 경우가 많습니다. 엑셀 명단이나 PDF 자료를 보고 한 칸 한 칸 옮겨 적다 보면 시간도 걸리고 오타도 납니다.

그렇다고 AI에 맡기자니 걸리는 게 있죠. 주민등록번호·계좌번호·연락처가 든 서식을 통째로 AI에 올려도 되나? claw-hwp는 이 두 가지 — 자동으로 채우되 개인정보는 안 새게 — 를 같이 해결합니다.

claw-hwp 양식 자동 채우기란?

클로드·코덱스에 설치하는 오픈소스 에이전트 스킬입니다. 빈 한글 서식과 데이터만 주면, 한국어로 말하듯 시키기만 하면 됩니다.

"이 엑셀 명단으로 강사 이력서 양식 채워줘"
"이 사람 정보로 지원서 빈칸 채워줘"
"견적 항목들 이 견적서 표에 넣어줘"

서식의 라벨(성명·생년월일·주소·연락처 …)을 읽어 데이터의 같은 항목을 알아서 맞춰 넣습니다. 어느 칸에 넣을지 애매하면 함부로 넣지 않고 물어봅니다(엉뚱한 칸에 잘못 채우는 것보다 안전). 원본 서식은 그대로 두고 값만 채우니 표·서식이 안 깨집니다.

주민번호·계좌번호는 어떻게 안전한가요?

보통 AI로 문서를 다루면 그 내용이 AI 대화(모델)에 올라갑니다. 개인정보가 든 서식이라면 이게 부담이죠. claw-hwp의 안전 모드는 방식이 다릅니다.

🔒 값은 AI 대화를 거치지 않습니다. AI는 "어떤 항목을 어느 칸에 넣을지"만 정하고, 실제 값(주민등록번호·계좌번호 등)은 사람의 컴퓨터 안에서 파일 → 파일로만 이동합니다. 즉 민감한 숫자가 모델에 전송되지 않습니다.

주민등록번호·전화번호처럼 하이픈이 들어가는 형식은 서식에 맞게 자동으로 맞춰 채웁니다.

설치하고 한 번에 채우기

Claude 앱 / Claude Code

claude plugin marketplace add https://github.com/DoHyun468/claw-hwp
claude plugin install claw-hwp@claw-hwp

설치 후에는 이렇게 하면 됩니다.

  1. 채울 빈 한글 서식(.hwp)과, 값이 든 엑셀·PDF·텍스트를 준비합니다.
  2. 클로드/코덱스에게 "이 데이터로 이 양식 채워줘"라고 말합니다.
  3. 서식 라벨과 데이터 항목을 맞춰 채웁니다. 개인정보 값은 대화에 안 올라갑니다.
  4. 채운 파일을 한컴오피스·한컴독스에서 열어 확인합니다(안 깨짐).

이런 서식에 씁니다

  • 인사·채용 — 이력서, 지원서, 재직·경력 증명 서식
  • 영업·회계 — 견적서, 거래명세서, 지출결의서
  • 계약·행정 — 계약서, 각종 신청서·동의서
  • 교육 — 강사 이력서, 출강 계획서, 수강 신청서

공통점은 "틀은 같고 값만 바뀌는 반복". 한 건이든 여러 건이든 이 반복을 대신 합니다.

자주 묻는 질문 (FAQ)

Q. 엑셀이나 PDF 데이터를 한글 양식에 자동으로 채울 수 있나요?

네. 엑셀·PDF에 흩어진 데이터를 읽어 한글 서식(.hwp)의 해당 칸에 자동으로 채워 줍니다. 한컴오피스가 없어도 됩니다.

Q. 주민등록번호·계좌번호 같은 개인정보가 AI에 노출되나요?

아니요. 안전 모드는 값을 AI 대화(모델)에 올리지 않고 파일에서 바로 칸에만 채웁니다. AI는 어떤 항목을 어디에 넣을지만 정합니다.

Q. 칸마다 매핑을 직접 설정해야 하나요?

빈 서식이면 항목 이름을 서식 라벨과 알아서 맞춰 채웁니다. 애매하면 함부로 넣지 않고 물어봅니다.

Q. 채운 파일이 한컴에서 안 깨지나요?

네. 원본 서식을 그대로 두고 값만 채우며, 한컴오피스·한컴독스에서 안 깨지고 열리는지 검증합니다.

Q. 주민번호처럼 형식이 정해진 값도 맞춰 주나요?

네. 주민등록번호·전화번호처럼 하이픈이 들어가는 형식은 서식에 맞게 자동으로 맞춰 채웁니다.

Q. 무료인가요?

네, MIT 라이선스 오픈소스입니다.
