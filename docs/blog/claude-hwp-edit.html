클로드로 한글(HWP) 문서 편집·작성·자동화하는 법 — 한컴오피스 없이 (2026)

한 줄 요약: claw-hwp를 설치하면 클로드(Claude)·코덱스(Codex) 같은 AI가 한글 문서(.hwp·.hwpx)를 한컴오피스 없이, 변환 없이 직접 읽고·만들고·편집합니다. 고친 파일이 한컴에서 안 깨지는지 매번 검증하고, 무료 오픈소스(MIT)입니다.

AI가 한글 파일을 못 읽어서 막힌 적 있나요?

ChatGPT·클로드로 업무를 자동화하다 보면 꼭 막히는 지점이 있습니다. 한글(.hwp) 파일. 회사 공문·보고서·사업계획서·서식은 대부분 한글로 오는데, AI는 이걸 바로 못 다룹니다. 그래서 보통은 이렇게 우회하죠.

  • PDF·워드로 변환한 뒤 업로드 → 표·서식이 깨지고, 다시 한글로 되돌릴 수 없음
  • 한컴오피스 자동화(COM) → 윈도우 + 한컴 라이선스 필수, mac 불가
  • 손으로 복붙 → 반복이 쌓이면 결국 사람이 다 함

claw-hwp는 이 우회들을 없앱니다. 원본 .hwp를 있는 그대로, 한컴 없이 편집합니다.

claw-hwp란?

클로드·코덱스에 설치하는 오픈소스 에이전트 스킬입니다. 설치 후에는 한국어로 말하듯 시키기만 하면 됩니다.

"이 보고서 표에서 매출 칸을 120억으로 바꿔줘"
"이 엑셀 데이터를 강사소개서 양식에 채워줘"
"표 하나 만들고 꼬리말에 쪽번호 넣어줘"

결과 파일은 한컴오피스·한컴독스(한글 웹)에서 그대로 열립니다 — 안 깨져요. 한컴오피스·LibreOffice·윈도우 전용 프로그램, 아무것도 필요 없습니다.

설치 후 한글 파일을 채팅에 올리거나 파일 이름을 말하면 자동으로 작동합니다.

이런 걸 할 수 있어요

  • 읽기 — 문서·표·셀 내용까지 통째로 추출
  • 글자·문단 꾸미기 — 굵게·색·글꼴·정렬·줄간격·자간
  • 표 — 만들기, 셀 병합·병합 해제, 행/열 추가, 셀 값 채우기
  • 개체 — 차트(20종+), 이미지, 도형, 서명·직인, 각주, 쪽번호, 수식
  • 양식 자동 채우기 — 엑셀·PDF에 흩어진 데이터를 한글 서식의 해당 칸에 자동 기입
  • 개인정보 안전 채우기 — 주민등록번호·계좌번호 같은 값을 AI 대화에 올리지 않고 파일에서 바로 칸에만 채움
  • 검증 — 고친 파일이 한컴에서 안 깨지고 열리는지 매번 확인

자주 묻는 질문 (FAQ)

Q. 클로드나 코덱스로 한글(HWP) 문서를 편집할 수 있나요?

네. claw-hwp를 설치하면 클로드·코덱스가 .hwp·.hwpx를 직접 읽고·만들고·편집합니다. 한컴오피스가 없어도 됩니다.

Q. .hwp를 .hwpx나 PDF로 변환해야 하나요?

아니요. 변환 없이 원본 .hwp를 있는 그대로 편집합니다. 고친 파일은 한컴오피스·한컴독스에서 그대로 열립니다.

Q. mac에서도 되나요?

됩니다. mac·윈도우에서 한컴오피스·윈도우 전용 프로그램 없이 작동합니다.

Q. 개인정보가 든 서식을 안전하게 채울 수 있나요?

네. 주민등록번호·계좌번호 같은 값을 AI 대화에 올리지 않고 파일에서 바로 칸에만 채우는 안전 모드가 있습니다.

Q. 엑셀·PDF 자료를 한글 양식에 자동으로 옮길 수 있나요?

네. 엑셀·PDF에 흩어진 데이터를 읽어 한글 서식의 해당 칸에 채워 줍니다.

Q. 브라우저 미리보기가 한컴과 100% 똑같나요?

아니요. 미리보기는 작업 중 빠른 확인용이라 한컴과 완전히 같지는 않습니다. 최종 확인·검토는 한컴오피스·한컴독스에서 하세요.

Q. 무료인가요?

네, MIT 라이선스 오픈소스입니다.
